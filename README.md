# my-first-web
## warehouse.html — Digital Twin คลังสินค้า 3D (แนวตั้ง 9:16)

เปิด `warehouse.html` ในเบราว์เซอร์ (ต้องต่ออินเทอร์เน็ตเพื่อโหลด Three.js จาก CDN)

- โมเดล 3D คลังสินค้า 4 โซน · 192 ช่องวาง · ประตูรับเข้า/ส่งออก · AGV 4 คัน (จำลองงานแบบเรียลไทม์)
- โหมดมุมมอง: หมวดสินค้า / ความหนาแน่น (heatmap) / แจ้งเตือนสต็อกต่ำ
- แตะช่องวางเพื่อดูรายละเอียดและสั่งรับเข้า/เบิกออก · ค้นหา SKU, ชื่อ หรือตำแหน่ง · แตะ AGV เพื่อติดตามกล้อง

## vault.html — ห้องเซฟทรัพย์จำนำ 3D (แนวตั้ง 9:16)

- เลขทรัพย์ 8 หลัก `YYMMCNNN` (ปี ค.ศ. · เดือน · 0=ตู้ขาว/1=ตู้เหลือง · ลำดับ) → ระบบคำนวณตำแหน่งเอง
- 6 คู่ตู้ (ขาว+เหลือง) วนทุก 6 เดือน: คู่ = ((เดือน−1) mod 6)+1 · ตู้ละ 12 ลิ้นชัก × 30 เลข · ลิ้นชัก = ⌈ลำดับ/30⌉
- ของชิ้นใหญ่นับเป็น 1 ช่องในลิ้นชักตามเลข แต่ตัวของแสดงที่ "มุมของใหญ่" พร้อมเส้นโยง
- ข้อมูลจาก Google Sheets (เผยแพร่เป็น CSV) หรือนำเข้าไฟล์ CSV · คอลัมน์: เลขทรัพย์, ชื่อทรัพย์, ชิ้นใหญ่, สถานะ, ยอดเงิน, วันที่รับ, หมายเหตุ
- **เช็คสต็อก**: เริ่มรอบเช็ค → สแกน QR/บาร์โค้ด (กล้องมือถือหรือเครื่องสแกน USB) หรือพิมพ์เลข → ระบบเทียบกับชีต (พบ / ไม่พบ / ของเกิน / ผิดลิ้นชัก) → กด "ลิ้นชักนี้เสร็จ" → ส่งออกผลเป็น CSV · พิมพ์ฉลาก QR รายลิ้นชักได้ · ความคืบหน้าบันทึกในเครื่อง ปิดหน้าแล้วกลับมานับต่อได้
